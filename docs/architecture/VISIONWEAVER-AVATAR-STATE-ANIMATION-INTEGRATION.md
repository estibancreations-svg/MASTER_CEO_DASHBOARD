## Dashboard contract

Expose the three exact board titles, character/state/voice/performance lineage, coverage profile and missing cells, current approval and stale-dependency status. Preserve the bottom Save action and previous approved avatar retrieval requirement. Store actual source assets and selected provider references; a generic snapshot does not prove inputs were loaded.

Add authored series/grade/style profiles, learning beats, perception/attention/task and response timelines, camera cues, exact text/phoneme revisions, world/zone/boundary state, event causes, contact/aftermath and continuation capsule references. Separate expected controls from capabilities actually supported by a provider. The eight camera heights and live schema mapping remain unresolved.

Display generated, saved, reviewed, approved, locked, stale and runtime-verified states accurately. An automated video analysis is evidence with limited scope, not a measured world model. Prompt counts, task completion and a progress percentage cannot certify an episode.

UI acceptance: save/reload pinned state and assets; resolve actual reference inputs; show version conflict and targeted stale descendants; distinguish mute/hide/remove; compare contact/reaction frames and text/audio; keep unsupported capabilities and unknown calibration visible. This commit implements documentation, not these UI behaviors.

## Change and source rules

Pinned versions and immutable asset hashes govern handoff. Record cause/scope/before/after/approver/source and targeted stale descendants. Preserve prior approved states and source uncertainty. Approved appearance outranks descriptive shorthand; ethnicity, language, accent and identity are separate. Do not overwrite corrected Black/fat representation through stylization or an older text description.

The full-coverage expansion is eight directions × eight configured heights = 64 full-body slots plus separate details; exact camera calibration remains unresolved. Keep older approved 32 masters and wardrobe-only 16 variants usable, and do not certify archived 24 studies as full coverage.
