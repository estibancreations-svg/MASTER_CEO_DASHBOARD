# VisionWeaver Global Reference Catalog Integration

**Date:** 2026-10-04

The CEO Dashboard recognizes the VisionWeaver / Design Studio Global Place + People Reference Catalog as a governed source-federation capability.

## Governance role

The dashboard does not treat public web availability or attribution as sufficient reuse permission. Source and asset records are classified through a rights gate before entering reusable catalogs.

Required executive controls:
- source provider registry
- source-terms review date
- rights class: GREEN / BLUE / YELLOW / ORANGE / RED
- ingestion audit
- geographic coverage
- location-pack approval
- stale-license/terms alerts
- identifiable-person and minors review flags
- blocked provider/content attempts
- provenance completeness

Canonical implementations:
- Design Studio: `docs/GLOBAL_PLACE_PEOPLE_REFERENCE_CATALOG-v1.md`
- VisionWeaver: `standards/GLOBAL_PLACE_PEOPLE_REFERENCE_CATALOG-v1.md`

Runtime ingestion, external API credentials, and provider-specific agreements remain implementation gates and are not certified merely by this documentation.
