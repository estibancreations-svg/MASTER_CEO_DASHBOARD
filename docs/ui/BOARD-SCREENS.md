# Board Screens (design layer)

Status: **VISUAL_REFERENCE**. Nothing here is IMPLEMENTED, LIVE or PRODUCTION. All numbers on board screens are illustrative.

Source: ten Gemini-regenerated "Master CEO Dashboard" boards plus Gemini's `PAGE_DESIGNS.md` inventory.

## What was added
- `src/boards/` holds one React screen per board, shared SVG/CSS primitives, and `BoardFrame`.
- `BoardFrame` adds two tabs to a module page: **Board design** (the reference screen) and **Live module** (the existing governed page, unchanged).
- Five themes via CSS variables on `.bd[data-theme]`: standard, executive (default, per the spec baseline), cyberpunk, glass, neumorphic.
- `MasterDashboard.tsx`: wraps Dashboard and 21 reachable modules (25 boards in total) in `BoardFrame`; adds an **Attached systems** sidebar section (VisionWeaver, LandWeaver, GrantOS, THELMA, CMGIO / MAP, EC Fabric).

## Gaps and open questions
1. **Settings** board is generic; no real permissions/identity design exists. **IT tab** has no board or module. Needs a spec.
2. **VisionWeaver** exists as an attached system but had no sidebar entry; now listed under Attached systems. It has no board.
3. Theme set: only 4 of 5 requested themes were generated by Gemini; the fifth (fintech) is not designed.
4. Gemini's "Complete / stored in Runway ML" claims are unverified and cannot be recorded as fact here.
5. Board text contains AI-garbled labels (e.g. percentages above 100, repeated years). Reproduced as drawn; fix before any implementation.
6. Numbering: board #26 is absent in the inventory.
7. Not covered by any board: manuscript-to-Director-approval pipeline, localized avatar / historical space framework, infrastructure status.
